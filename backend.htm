Connect this page to your Firebase project

The API key in your project details was not included yet. Add it in the Firebase configuration inside this file, then complete these one-time steps.

1Enable Email/Password in Firebase Authentication and create the admin account there.
2In Firestore, create users/{adminUid} with role: "admin". The UID comes from Authentication.
3Create the Firestore database, publish the access rules below, and host both HTML files on Firebase Hosting or another HTTPS host.
4Add the Firebase web API key to both pages. The key identifies the project; Firestore rules protect its data.
The provided username and password are not embedded here. A password in HTML could be read by anyone. For access, create a Firebase Auth account and grant its UID the admin role.
